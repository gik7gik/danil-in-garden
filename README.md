# Danil in Garden

Браузерная игра о выращивании растений, уходе за садом и микрозеленью.

## Локальный запуск

Откройте `index_56.html` в браузере.

## Публикация

GitHub Actions автоматически публикует сайт в GitHub Pages после каждого push в ветку `main`. Во время сборки `index_56.html` становится главной страницей `index.html`, поэтому локальная структура проекта остаётся неизменной.
